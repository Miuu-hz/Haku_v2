## 1. ทดสอบชิ้น ก บน Z Fold5 (~20 นาที) — สำคัญที่สุด
เป็นเกณฑ์ผ่านที่ขวางทั้งแผน (ถ้าไม่ผ่านต้องทบทวน D1 D3) โมเดล Gemma 4 E2B ดาวน์โหลดไว้แล้วที่ `F:\Haku Project\models\gemma-4-E2B-it.litertlm` (2.4 GB)

เตรียมเครื่อง: เปิด Developer options → USB debugging แล้วเสียบสาย จากนั้นใน Git Bash:
```bash
export JAVA_HOME="/f/Android Studio/jbr"; export PATH="$PATH:/f/AndroidSDK/platform-tools"
cd "/f/Haku Project/haku-v2"
adb devices        # ถ้ามี emulator ด้วย ให้ใส่ -s <serial ของ Fold5> ทุกคำสั่ง adb
adb shell mkdir -p /data/local/tmp/haku
adb push "F:/Haku Project/models/gemma-4-E2B-it.litertlm" /data/local/tmp/haku/
./gradlew --no-daemon :androidApp:installDebug

# GPU (รัน 2-3 รอบ รอบแรกมีการอุ่นเครื่อง)
adb logcat -c
MSYS_NO_PATHCONV=1 adb shell am start -S -n com.bbpillow.haku/.SpikeActivity --es model /data/local/tmp/haku/gemma-4-E2B-it.litertlm --es backend gpu
adb logcat -s HakuSpike:I          # รอจนขึ้น DONE หรือ ERROR แล้วกด Ctrl+C

# CPU
adb shell am force-stop com.bbpillow.haku; adb logcat -c
MSYS_NO_PATHCONV=1 adb shell am start -S -n com.bbpillow.haku/.SpikeActivity --es model /data/local/tmp/haku/gemma-4-E2B-it.litertlm --es backend cpu
adb logcat -s HakuSpike:I
```
อ่านค่า: `LOAD ms` เวลาโหลด · `ttftMs` เวลาโทเค็นแรก · `tokPerSec` ความเร็ว · `pssMB` หน่วยความจำ
**ส่งผลลัพธ์ใน logcat ให้ Claude** แล้วจะบันทึกลง `docs/spikes/` ให้ ผ่านเมื่อ: มีคำตอบภาษาไทยขึ้นบนเครื่อง และวัด TTFT ได้

หมายเหตุ: บน emulator ทดสอบได้แค่ว่า native library โหลดได้ (ผ่านแล้ว) เพราะ emulator มี RAM 2 GB ไม่พอสำหรับโมเดล

## 16. ติดตั้งจริงครั้งแรก (แอปเต็ม)
แอปเปิดขึ้นที่หน้าเริ่มใช้งานจริงแล้ว (ไม่ใช่ข้อมูลจำลอง) ทดสอบบน Z Fold5 ราว 20 นาที + เวลาดาวน์โหลดโมเดล (~2.6 GB ใช้ Wi-Fi)
1. ติดตั้งแบบเริ่มใหม่: `adb uninstall com.bbpillow.haku` แล้ว `./gradlew --no-daemon :androidApp:installDebug`
2. เปิด log ไว้อีกหน้าต่าง: `adb logcat -s HakuShell HakuModel HakuCapture AndroidRuntime`
3. เปิดแอป → หน้าเริ่มใช้งาน ทำตามทีละขั้น:
   - **สิทธิ์**: ทุกข้อเริ่มจาก "ปิด" ติ๊กตำแหน่ง กิจกรรม ปฏิทิน แล้วกดขอ → ระบบถามตำแหน่ง (เลือก "ขณะใช้แอป") กิจกรรม ปฏิทิน ทีละหน้าต่าง
     ถ้าติ๊กตำแหน่งเบื้องหลังไว้ด้วย ระบบจะถามแยกหลังสุด (Android 11+ มักพาไปหน้าตั้งค่า ให้เลือก "อนุญาตตลอดเวลา" แล้วกดย้อนกลับ)
   - **คำลงท้าย/ชื่อเรียก**: ดูตัวอย่างไดอารีเปลี่ยนตาม
   - **โมเดล**: เครื่อง 12 GB ควรเห็นทั้ง E2B และ E4B กดดาวน์โหลด ดูแถบคืบหน้าวิ่ง ลองกดหยุด → เล่นต่อ (ควรต่อจากเดิม ไม่เริ่ม 0)
     ลองพับ/กางเครื่องระหว่างดาวน์โหลด ไม่ควรเริ่มใหม่ · ไฟล์ไปอยู่ที่ `/sdcard/Android/data/com.bbpillow.haku/files/models/` (`.part` ระหว่างโหลด)
   - **ล็อก**: กดเปิด → หน้าต่างสแกนนิ้ว/PIN ของระบบ
   - **สถานที่แรก**: ติดตั้งใหม่มักยังไม่มีข้อมูล ข้ามได้
   - กด "เริ่มใช้ Haku" → เข้าแท็บหน้าแรก / ไทม์ไลน์ / ความจำ
4. ตรวจว่าการจับข้อมูลเริ่มแล้ว (เริ่มเฉพาะเมื่อให้ตำแหน่ง + กิจกรรม): `adb logcat -s HakuCapture` ควรเห็นบรรทัดเริ่ม
   หรือ `adb shell am broadcast -n com.bbpillow.haku/.CaptureDebugReceiver -a com.bbpillow.haku.debug.DUMP`
5. ปิดแอปจาก recent แล้วเปิดใหม่ → ถ้าเปิดล็อกไว้ต้องสแกนก่อน · ไม่ควรกลับไปหน้าเริ่มใช้งาน
6. ถ้าดาวน์โหลดค้างตอนปิดแอป: เปิดแอปใหม่ ระบบต่อจากไฟล์ `.part` เอง
7. ลองโหลดโมเดลที่ดาวน์โหลดมา: `adb shell am start -n com.bbpillow.haku/.SpikeActivity` (ไม่ใส่ `--es model` จะใช้ไฟล์ที่ดาวน์โหลดในแอป) ดู `adb logcat -s HakuSpike`
8. ตั้งแบตเป็น "Unrestricted" แล้วใช้ชีวิตหนึ่งวัน พรุ่งนี้เปิดแท็บหน้าแรก กดการ์ดเมื่อวาน → ควรเปิดวันนั้นในไทม์ไลน์

ส่ง Claude: บรรทัด error ใน logcat (ถ้ามี) · หน้าจอที่ค้างหรือว่าง · เวลาที่ใช้ดาวน์โหลด
ข้อจำกัดที่รู้: ดาวน์โหลดไม่มี foreground service ถ้าปิดจอนานระบบอาจหยุด (เปิดแอปใหม่ต่อได้) · ไม่ตรวจ hash ไฟล์ ตรวจแค่ขนาด · ฐานข้อมูลยังไม่เข้ารหัส ล็อกเป็นแค่ประตู (D11)
