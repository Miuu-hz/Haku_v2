## ชิ้น ก — แกนกลางเรียกโมเดลในเครื่องผ่านชั้นห่อหุ้ม

1. เป้าหมาย
2. สิ่งที่ยกมาจาก Gallery: ไม่คัดลอกไฟล์ เขียนคลาวใหม่ราว 60 บรรทัดตามแบบ `LlmChatModelHelper.kt` (ขั้น สร้าง Engine → เปิด Conversation → ส่งข้อความ → ปิด)
   - ไม่ยก `Model.kt` · Hilt · ViewModel · `MetricsTracker` (ใน 1.0.19 ปิดอยู่แล้ว)
   - `Context` ใช้แค่สามจุด แทนด้วยพารามิเตอร์ธรรมดา: ที่อยู่ไฟล์โมเดล · โฟลเดอร์ native lib (NPU) · โฟลเดอร์ cache
3. interface ใน `core/thinking` (ชื่อเท่านั้น)
   - ตัวเรียกโมเดล · ข้อมูลเข้า · ข้อมูลออก · ค่าตั้งโมเดล
4. ตัวทำงานจริงใน `androidApp/platform`
5. การได้ไฟล์โมเดลลงเครื่อง: ดาวน์โหลดเองแล้ว `adb push` ก่อน ยังไม่ทำระบบดาวน์โหลดในแอป
   - Gemma 4 E2B ~2.41 GiB (ต้องการ RAM 8 GB) · E4B ~3.41 GiB (ต้องการ RAM 12 GB) Z Fold5 ใช้ได้ทั้งคู่
   - ไฟล์จาก `litert-community/gemma-4-E*B-it-litert-lm` ตาม commit ที่ Gallery 1.0.19 ระบุ
6. เทสต์
   - เทสต์หน่วยในแกนกลางด้วยตัวเรียกโมเดลปลอม
   - เทสต์บนเครื่องจริง
7. สิ่งที่วัด: เวลาโหลดโมเดล · เวลาโทเค็นแรก · โทเค็นต่อวินาที · หน่วยความจำ — เทียบ GPU กับ CPU
   - เวลาโทเค็นแรกจับเวลาเองตั้งแต่ส่งถึงข้อความแรกที่ไม่ว่าง (ตัวเลขจากตัวรันต้องเปิด flag ทดลองซึ่งยังไม่ใช้)
8. เกณฑ์ผ่าน: สร้างข้อความตอบกลับได้บนเครื่องจริง และวัดเวลาโทเค็นแรกได้
9. ถ้าไม่ผ่าน → ทบทวน D1 D3

## ชิ้น ข — ตัดคำไทยและดัชนีข้อความเต็ม

1. เป้าหมาย
2. ตัวตัดคำของระบบปฏิบัติการที่ใช้
3. ฐานข้อมูลที่ฝังมากับแอป (ตัวเลือก)
4. interface ใน `core/memory` (ชื่อเท่านั้น)
5. ชุดข้อมูลทดสอบหมื่นรายการ (มาจากไหน)
6. เทสต์: คำไทยกลางประโยค · ไทยปนอังกฤษ
7. สิ่งที่วัด: เวลาค้น
8. เกณฑ์ผ่าน: ค้นคำไทยกลางประโยคเจอ และหมื่นรายการต่ำกว่า 50 ms
9. ถ้าไม่ผ่าน → ทบทวน D5

## ชิ้น ค — โมเดลฝังความหมายในเครื่อง

1. เป้าหมาย
2. โมเดล: EmbeddingGemma 300M (รูปแบบไฟล์และตัวรัน)
3. interface ใน `core/memory` (ชื่อเท่านั้น)
4. สิ่งที่วัด: เวลาฝังหนึ่งย่อหน้า · หน่วยความจำ
5. เกณฑ์ผ่าน: ต่ำกว่า 300 ms และต่ำกว่า 400 MB
6. ถ้าไม่ผ่าน → เลื่อน P1.5 และทบทวน D6

## ชิ้น ง — ถอดเสียงไทยด้วย Gemma 4

1. เป้าหมาย
2. ชุดเสียงทดสอบ 30 นาที (ใครพูด เรื่องอะไร บทถอดความที่ถูกต้องมาจากไหน)
3. วิธีป้อนเสียงเข้าโมเดล: Gemma 4 รองรับเสียงในตัว ส่งเป็นเนื้อหาเสียงคู่กับข้อความสั่งให้ถอดความ ในการสนทนาเดียวกับชิ้น ก (ตัวรันเสียงใช้ CPU)
4. วิธีคำนวณอัตราผิดระดับคำ (ต้องตัดคำไทยก่อนนับ)
5. เกณฑ์ผ่าน: อัตราผิดต่ำกว่า 25%
6. ถ้าไม่ผ่าน → D16 ส่งเครื่องที่บ้าน · ย้ายชั้นเสียงไปท้ายช่วงที่ 6
