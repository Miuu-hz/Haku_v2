## บทบาท

- ข้อมูลไดอารี ตำแหน่ง ปฏิทิน เวกเตอร์ บรรทัด "ตอนนี้" และบันทึกการเชื่อมต่อ **อยู่ในเครื่องเท่านั้น** เราอ่านไม่ได้
  อาจเข้าข้อยกเว้นใช้ส่วนตัว ม.4(1) สำหรับผู้ใช้ ⚖️ แต่เราเป็นผู้ออกแบบ จึงยังต้องทำตามหลัก ม.23 (แจ้ง) ม.33 (ลบ) ม.37 (ความปลอดภัย) เพื่อให้คำโฆษณา "ไม่ออกจากเครื่อง" เป็นจริง
- การดาวน์โหลดโมเดลจาก Hugging Face: เครื่องผู้ใช้ต่อไปที่ `huggingface.co` และ CDN ของเขาเอง เราไม่ได้รับข้อมูลใด ๆ
  แต่ Hugging Face (สหรัฐฯ) เห็นหมายเลข IP เวลา และ User-Agent ⚖️ ว่าเป็นการโอนข้อมูลส่วนบุคคลออกนอกประเทศโดยเรา (ม.28) หรือไม่

## สิ่งที่ทำถูกแล้ว

- **release ไม่มีตัวรับ debug**: ตรวจโดย merge manifest ของ release (`:androidApp:processReleaseMainManifest`) แล้ว
  `AskDebugReceiver` `EmbedDebugReceiver` `CaptureDebugReceiver` `SpikeActivity` `ShowcaseActivity` ไม่อยู่ในไฟล์ผล (0 รายการ)
  ทั้งหมดประกาศใน `androidApp/src/debug/AndroidManifest.xml` และโค้ดอยู่ใน `androidApp/src/debug/kotlin` · โค้ดใน `src/main` ไม่อ้างถึงคลาสเหล่านี้ · `src/release` มีแค่ `DemoTools.kt` ที่ว่าง
- **log ใน release ไม่มีข้อมูลส่วนบุคคล**: log ที่เพิ่มใน `src/main` (AppGraph, NightlyWorker, ModelDownloader, LiteRtTextEmbedder) พิมพ์แค่ชื่อคลาสของ exception หรือจำนวน · ผลการดาวน์โหลดเก็บแค่ชื่อคลาส เพราะข้อความ exception อาจมี URL
- **บันทึกการเชื่อมต่อเก็บน้อยที่สุด** (ม.22): เก็บแค่ host และ path ตัด query string และ user-info ทิ้ง (`ConnectionRecord.hostAndPath`) ลิงก์ CDN ที่มี token จึงไม่ถูกเก็บ · เก็บ 30 วัน · ลบด้วย "ลืมทุกอย่าง" · แสดงให้ผู้ใช้ดูได้ในหน้าความโปร่งใส (ม.23, ม.30)
- **เวกเตอร์ตามบรรทัดต้นทาง** (ม.33): ทุกการลบใน `IndexedMemoryRepository` ลบเวกเตอร์ด้วย แก้ข้อเท็จจริงแล้วเวกเตอร์เดิมถูกลบ · `VectorIndexer.save` ไม่เขียนเวกเตอร์ของบรรทัดที่ถูกลบระหว่างฝังความหมาย · `secure_delete=ON` · "ลืมทุกอย่าง" ล้างตาราง `vectors` แล้ว compact
- **นำเข้าโมเดลผ่าน SAF**: อ่านเฉพาะไฟล์ที่ผู้ใช้เลือก ไม่ขอสิทธิ์อ่านที่เก็บข้อมูล · กรองชื่อไฟล์ (`ActiveModel.isSafeFileName`) กัน path traversal
- **ไม่มีบัญชี/โทเคน Hugging Face**: เลือก Qwen2.5 1.5B แทน Gemma 3 1B ที่ต้องล็อกอิน จึงไม่มีข้อมูลบัญชีผู้ใช้ไปถึง Hugging Face · EmbeddingGemma 2 ไม่ต้องล็อกอินเช่นกัน
- **ไม่มีจุดประสงค์ใหม่** (ม.21): เวกเตอร์และบรรทัด "ตอนนี้" ใช้เพื่อตอบคำถามของผู้ใช้เองจากบันทึกของเขาเอง ในเครื่อง เหมือนดัชนีค้นหาเดิม จึงไม่ต้องขอความยินยอมใหม่ แต่ควรอยู่ใน privacy notice (ข้อ 3 และ 4)
- **กันคำสั่งแทรกในแชต**: `INJECTION_RULE` ปฏิเสธคำขอลืมกฎ/บอกพิกัด · ตอบโดยไม่มีบันทึกรองรับแล้วมีเวลา ตัวเลข สถานที่ หรือคำพูดที่ไม่มีที่มา → ตัดทิ้ง ใช้คำตอบจากการค้นแทน (`ChatPresenter.answer`) · คำถามไม่ถูกนับเป็นข้อเท็จจริงอีกต่อไป จึงพูดซ้ำพิกัดที่ผู้ใช้พิมพ์เข้ามาไม่ได้ · เวกเตอร์และดัชนีที่อ่าน provenance ไม่ออกถือเป็น `EXTERNAL` (เชื่อถือน้อยสุด) · ข้อควรรู้: ชื่อนัดในปฏิทินคนอื่นเขียนได้ (คำเชิญประชุม) จึงเป็นช่องแทรกคำสั่งที่ยังเหลืออยู่ ควรมีข้อทดสอบ `injection` ที่มาจากชื่อนัดใน `demo_eval.py`
- **ไม่ส่งข้อมูลออก**: ตัวนับ egress ยังเป็น 0 เพราะการเชื่อมต่อเดียวคือดาวน์โหลดโมเดล (`carriesPersonalData = false`) และ `allowBackup=false` ยังอยู่

## ต้องแก้ก่อน closed beta

1. ต่อ D11 เข้ารหัส DB และไฟล์ในเครื่องด้วยกุญแจ Keystore (ข้อ 1)
2. แจก release build เท่านั้น และใส่ `android:permission="android.permission.DUMP"` ให้ตัวรับ debug ทั้งหมด (ข้อ 2)
3. ลบโมเดลฝังความหมาย = ล้างตาราง `vectors` + บอกในการ์ด (ข้อ 3)
4. แก้ข้อความแจ้งการดาวน์โหลดให้บอกว่า Hugging Face (สหรัฐฯ) เห็น IP และใส่ใน privacy notice (ข้อ 4)
5. กัน `*.jsonl` และ `__pycache__/` ใน `.gitignore` และเอา `.pyc` ที่ commit ไปแล้วออก (ข้อ 5)

ข้อ 6–9 ทำในช่วงถัดไปได้

## คำถามสำหรับทนาย ⚖️
